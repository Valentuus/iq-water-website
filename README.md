# 💧 IQ Water Website

A website showcasing water vending systems, built as a student web development project using HTML, CSS and JavaScript.

## Features

- Product catalog with images, prices and descriptions
- Product overview and order modals
- Order form with basic validation
- Form details saved locally using localStorage
- Automatic customer review slider
- Modal closing by button, outside click or Escape key
- About and contact pages
- CSS animations and smooth scrolling

## Technologies

- HTML5
- CSS3
- JavaScript
- Bootstrap Icons
- Google Fonts

## Getting Started

Download or clone this repository, then open `index.html` in your browser.

No installation or build step is required. An internet connection is needed to load external fonts and icons.

## Project Files

- `index.html` — homepage and product catalog
- `about.html` — company information
- `contacts.html` — contact details
- `css/` — page styles and animations
- `js/` — interactive functionality
- `images/` — website images
- `testCases.txt` — manual testing scenarios

## Project Scope

This is a frontend demonstration. The order form validates input and stores details in the browser; it does not send orders to a server.
